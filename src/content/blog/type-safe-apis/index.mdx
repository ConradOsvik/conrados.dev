## The problem

Every web developer has experienced it: you change a field name in the database and something breaks silently in the frontend three weeks later.

## Schema as the source of truth

By deriving API types directly from your database schema, you eliminate an entire class of bugs. Tools like Drizzle and Zod make this straightforward.

## Trade-offs

This approach works best for teams that own both the backend and frontend. For public APIs, you might still want a separate contract layer.
